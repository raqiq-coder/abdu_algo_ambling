## Условие
Реализовать встроенный в javascript метод `promise.all()`. На вход массив промисов, на выходе промис, который заверщается ошибкой если хоть один промис из списка был rejected, а если все resolved то возвращает массив их результатов, при этом сохраняя порядок.

## Идея решения

Условие выдает часть решения. Функция возращает `Promise`, на выходе массив значений которые вохращают промисы, значит должен быть результирующий массив где будем складывать результаты. Итерируемся по входному массиву и дожидаемся каждого промиса. Если промис валится сразу `reject` без разговоров, вот если он `resolve`-ится, то тут уже добавляем его значение в результирующий массив. Дальше нам надо как-то понять когда вызвать `resolve()`, то есть нам нужно отследить когда мы закончим итерироваться по массиву. Для этого заводим счетчик и считаем, если счетчик и длинна массива совпадут, то мы прошлись до конца и можно вызывать `resolve(result)`

## Сложность

Time O(n), Space O(n)

## Заметки

В самом начале положил вызов `resolve()` вне `then` и вообще вне цикла. Забыл что вне `then`, код работает синхронно. То есть код внутри `new Promise` выполнится синхронно, если он конечно не в `then` или `await`
