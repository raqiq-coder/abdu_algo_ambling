## Условие

Учитывая целочисленный массив `nums` и целое число `k`, верните `k` наиболее часто встречающихся элементов в массиве.

## Идея решения

Идея состояла в том, чтобы посчитать частоты каждой цифры и запаковать их в хэш-таблицу. Дальше нужно отсортировать по убыванию (сортировку делать по значению). Далее срезаем массив до значения `k` и выдаем массив ключей хэш-таблицы

## Сложность

Time O(nlogn), Space O(n)
