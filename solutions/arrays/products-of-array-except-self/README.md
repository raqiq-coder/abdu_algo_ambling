## Условие

На вход дан массив `nums`, возвращаем массив `output`, где `output[i]` является произведением всех элементов nums, кроме `nums[i]`.

Гарантируется, что каждое произведение соответствует 32-разрядному целому числу.

## Идея решения

Вычислить общее произведение всего массива. Далее это общее произведение делим на элементы исходного массива и результат записываем в результирующий массив по нужному индексу. Есть нюанс с нулями в исходном массиве: если в массиве есть один ноль, то на месте всех индексов в результирующем массиве будет ноль кроме, того где сидит сам ноль: `[0, 1, 2, 3] => [6, 0, 0, 0]`. Если нулей будет больше чем один, то все элементы обнуляются `[0, 0, 1, 2] => [0, 0, 0, 0]`

## Сложность

Time O(n), Space O(n)
