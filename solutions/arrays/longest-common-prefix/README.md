## Условие

Вам задан массив строк `strs`. Нужно вернуть самый длинный общий префикс из всех строк.

Если самого длинного общего префикса нет, верните пустую строку `""`.

## Идея решения

Выбрать из входного массива певрое слово `firstWord`. Далее запускаем цикл `while` c внешним индексом. Если слово в массиве не начинается с `firstWord`, то укорачиваем
`firstWord` с конца на один символ. Если слово начинается с `firstWord`, то тогда увеличиваем индекс, следовательно переходим к следующему элементу массива. Также есть доп условие: если мы достигли конца массива или `firstWord` уже пустой, то возвращаем `firstWord`.

Смысл в том, что пока слово не будет начинаться с `firstWord` мы не переходим к следующему слову в массиве и укорачиваем `firstWord` пока проверка не пройдет.
