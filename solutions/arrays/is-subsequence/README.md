## Условие

Вам даны две строки s и t, возвращающие значение true, если s является подпоследовательностью t, или false в противном случае.

Подпоследовательность строки - это новая строка, которая формируется из исходной строки путем удаления некоторых (может не быть ни одного) символов без изменения относительного расположения оставшихся символов. (т.е. "ace" является подпоследовательностью "abcde", а "aec" - нет).

## Идея решения

В этой задаче важна именно последовательность букв. Следовательно использовать Set не получится. Нужно что-то придумать с индексами.
Решение завести два индекса исмотреть на оба слова сразу. Если буква совпадает и там и там, то увеличиваем индекс который бегает по `source`, а индекс который бегает по
`target` увеличиваем и когда нашли и когда не нашли. Итерируемся пока не достигли конца `source` и `target`. Результатом возвращаем сравение значения индекса который бегал по `source` (если все ок то значение должно быть равно длине `source`) и длины `source`.

## Сложность

Time O(n+m), Space O(1)
