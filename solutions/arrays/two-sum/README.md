## Условие

Дан массив чисел `nums` и число `target`. Вернуть индексы двух элементов,
сумма которых равна `target`. Ровно одно решение, один элемент — один раз.

## Идея решения

Хеш-таблица: за один проход храним `значение -> индекс`. Для каждого `nums[i]`
проверяем, встречали ли уже `target - nums[i]`. Если да — пара найдена.

## Сложность

Time O(n), Space O(n).

## Заметки

Наивный вариант — два вложенных цикла, O(n²). Хеш-таблица меняет лишнюю память
на линейное время.
