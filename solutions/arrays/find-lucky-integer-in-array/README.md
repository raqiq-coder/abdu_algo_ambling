## Условие

Вам задан массив целых чисел arr, счастливое целое число - это целое число, частота которого в массиве равна его значению.

Верните наибольшее счастливое целое число в массиве. Если счастливого целого числа нет, верните -1.

## Идея решения

Заполнить хэш-таблицу частотами с которыми появляются числа в массиве. Потом еще одним циклом проходиться по таблице и проверять равенство ключа и значения
и найти максимум
