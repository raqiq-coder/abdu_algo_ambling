## Условие

Дан массив символов, представляющий строку s. Напишите функцию, которая преобразует строку в обратном порядке.

Вы должны сделать это, изменив входной массив на месте, выделив O(1) дополнительной памяти.

## Идея решения

Завести два указателя, один на начало другой на конец. Далее итерируемся по массиву заменяя местами противоположные элементы. Если левый индекс будет больше или равен правому то заканчиваем цикл

## Сложность

Time O(n), Space O(1)
